Nyxium Documentation

Get started with Nyxium!

Setup

Begin by downloading Nyxium by clicking the download button. This will install Nyxium on to your system and add it to PATH

Next, open your IDE of choice, and create a file with the .nyx extension.

Finally, enter your Nyxium code into the file and run

nyxium file.nyx

Nyxium Syntax

Output

Use say() to output text into the console.

say("Hello from Nyxium")

Variables

Create variables using var.

var x = 5
say(x)

If

As of Nyxium v1.0, Nyxium only supports if.

var x = 10
if x == 10
  say("X is 10!")
end

Logical Operators

==, !=, >, >=, <, <=

Loop

Nyxium provides basic loop support, with loop int.

loop 5
   say("Nyxium")
end

Comments

Nyxium has support for one-line comments as of version 1.0.0.

@ This is a Nyxium comment

Night

Functions are made with the night syntax.

night hello{
    say("Hello!")\n}

Lose

The lose function is what makes Nyxium unique. It unloads a function.

get math
lose math

Imports

Math

Add

The add function in Nyxium is exclusive to the math module. This adds 2 integers together

get math
add(1, 5)

Subtract

The subtract function in Nyxium is also exclusive to the math module. This subtracts 2 integers together

get math
subtract(5, 1)

Multiply

The multiply function in Nyxium is yet again, exclusive to the math module. This multiplies 2 integers together

get math
multiply(4, 5)

Divide

The divide function is the last function (as of v1.2.5) inside the math module. This divides 2 integers together

get math
divide(20, 5)

Wait

The wait function is the only function in this module. This waits for the ammount of seconds you want.

get wait
wait(12)

Random

As of version 1.2.5, randint is the only function in the random module.

get random
randint(1, 10)

Nyxium errors

[module name] not found.

This simply means you haven't used the get function to initilise the module

Nyxium line 5: Wait module not found, try using `get wait`

File not found.

You have likely typed the name wrong, re-run the command and ensure its the correct name

Error: Nyxium file not found

Unknown Command

You may have found a bug or typed a function wrong.

Unknown command: Line 6

Library disabled

This means you have used the lose function and the library was already disabled.

Nyxium line 15: Maths library already disabled!
